Computing in Data Analytics and AI

For this project, I looked at two different computing techniques that can help people in data analytics and AI. I chose AI data analysis and Kaggle because both can help people work with data, learn new skills, and solve problems in different ways.

AI Data Analysis

AI data analysis can make working with data a lot easier and faster. Tools like ChatGPT can help look through data, make charts, find patterns, and help with coding. This can save a lot of time, but you still need to understand what the results mean because AI can make mistakes. I think this is a good example of humans and computers working together instead of technology just replacing people. For me, this means I still need to learn things like Python, SQL, and statistics, but I also need to learn how to use AI correctly and know when an answer does not look right.

Kaggle

Kaggle is a website where people can practice working with data, use real datasets, share their work, and learn from other people. Instead of trying to learn everything by yourself, you can see how other people solve problems and then try it yourself. Kaggle also has competitions and notebooks where people can practice their skills on real problems. I think this can help me get better at data analysis because I am actually practicing what I learn instead of only reading about it. It can also help me build projects that I could eventually put in my portfolio.
